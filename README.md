# Online Secure Student Information System (OSSIS)

## Secure Software Engineering Project

This repository contains the project report and Java implementation for the Online Secure Student Information System (OSSIS).

## Project Contents
- Project Report (PDF)
- Secure Login Java Code
- Documentation Files

## Project Description
OSSIS is a secure web-based student information system designed to protect student academic records using secure software engineering principles.

The system includes:
- Secure login authentication
- Role-Based Access Control (RBAC)
- SQL Injection prevention
- Password hashing using BCrypt
- Account lockout protection
- Secure session management

## Technologies Used
- Java
- MySQL
- BCrypt
- PreparedStatement
- Secure Software Engineering Principles
